Примечание: F-Droid нужны привилегии администратора (root), чтобы установить Привилегированное расширение в качестве системного привилегированного приложения.

Используя системные привилегии или разрешения, https://f-droid.org/packages/org.fdroid.fdroid может устанавливать, обновлять или удалять приложения. Эти привилегии может получить только приложение, отмеченное как системное.

Именно в этом роль Привилегированного расширения: это небольшое отдельное приложение, которое можно установить как системное и которое будет взаимодействовать с основным приложением с помощью AIDL IPC.

У такого подхода есть ряд преимуществ:

* Использует меньше места на диске в системном разделе
* Системные обновления больше не удаляют F-Droid
* Безопасная установка с правами администратора

Большинство пользователей вместо этой сборки хотят устанавливать обновления с помощью OTA. Архив с обновлением называется https://f-droid.org/packages/org.fdroid.fdroid.privileged.ota. 
Он предназначен для обновления привилегированного расширения, если оно было установлено с помощью OTA ZIP.
